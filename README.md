# Proxify

Proxify is a lightweight reverse proxy written in Go.

It sits between clients and upstream services, forwarding incoming HTTP requests and returning upstream responses while providing production-oriented capabilities such as load balancing, health checks, rate limiting, logging, metrics, and graceful shutdown.

## Features

- Reverse proxy
- Request forwarding
- Response forwarding
- Configurable upstreams
- Load balancing
- Health checks
- Rate limiting
- Logging
- Metrics
- Graceful shutdown

## Technology

- Go
- Docker Compose
- YAML
