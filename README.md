# Proxify

Proxify is a reverse proxy written in Go that sits between clients and upstream services, forwarding HTTP requests while providing load balancing, health checks, rate limiting, logging, metrics, and graceful shutdown.

## Features

- Reverse proxy
- Request forwarding
- Response forwarding
- Configurable upstreams
- Load balancing
- Health checks
- Rate limiting
- Logging
- Metrics
- Graceful shutdown

## Technology

- Go
- Docker Compose
- YAML
